# Merchant playtest

Done = every line below works for a first-time player, start to title card.
Play fresh: New Career, Merchant. Don't skip ahead.

## The run

1. Title, New Career, Merchant file, sign, ID form, Dez's form
2. Launch: first water run, Drip to Greenhouse
3. The rig ahead in Tiberine: go in or don't
4. First profit, top off spare hold, first weekly payment
5. Marcellus jump exit: the Tallyman ambush. Try losing it once
6. Franz at Four: bounty, marines, Red Stork alive or dead
7. Saltgate bar: hire Fay and Mersham, then fly with them (Tab orders)
8. Pay it off (or take the Navy offer), papers, the Wall, the Crossroads, title card

Also try once: get beaten by a raider (airlock and fight), run the reserve dry, miss a payment.
